# Как объяснить Trace Lens

Открой синтетическую трассу, найди ошибочную попытку платёжного провайдера, затем покажи успешный повтор. Импортируй OTLP JSON, открой некорректный файл и продемонстрируй, что предыдущая трасса сохранилась.

Что разобрать:

1. Почему UnixNano нельзя сразу преобразовать в Number? Покажи тест с разницей 1234 наносекунды.
2. Почему сумма длительностей дочерних spans может превышать время родителя? Нарисуй пересекающиеся интервалы.
3. Зачем Worker и generation counter? Воспроизведи быстрое открытие двух файлов.
4. Почему дерево обходится итеративно? Прогони тест на глубину 10 000.
5. Почему p95 spans не равен p95 запросов? Объясни единицу наблюдения и вложенность.

Практика: добавь сравнение двух трасс по имени операции, предусмотрев отсутствующие spans и разные trace IDs. Не называй self time CPU time и не рисуй причинный critical path только по временным интервалам. Для DevOps этот проект показывает чтение распределённых трасс и понимание наблюдаемости; для frontend — обработку данных, асинхронность и доступный интерфейс.

Личный проект с AI-помощью. Проверяй собственное понимание изменением кода и воспроизводимыми тестами.
